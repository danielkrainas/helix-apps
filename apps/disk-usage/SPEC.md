# Disk Usage Analyzer

Drop-in replacement for Baobab.

## Purpose
Visualize disk usage.

## Main windows
- Treemap or ring chart of a location.
- Folder list.

## Contracts used
- XDG portals: FileChooser, OpenURI.
- GSettings: `org.gnome.baobab`.

## Non-goals
- Exact visual style of current Baobab.
