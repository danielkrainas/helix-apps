# Contacts

Drop-in replacement for GNOME Contacts.

## Purpose
Manage contacts.

## Main windows
- Contact list and details.
- Editor.
- Linking / merging.

## Contracts used
- Evolution Data Server or equivalent.
- GNOME Online Accounts.
- XDG portals: OpenURI.
- GSettings: `org.gnome.Contacts`.

## Non-goals
- Full EDS backend parity on day one.
